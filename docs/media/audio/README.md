# Engine synthesizer — offline renders and spectra

Generated by `node apps/testbed-web/e2e/audio_engine.mjs` (owner row 73). Each sweep is the
director's command stream (`cargo run -p wp_audio --example engine_sweeps`) rendered through the
testbed's real `VoicePool` and engine AudioWorklet in an `OfflineAudioContext` (48 kHz, chase
camera 6 m behind, exterior unless noted). Spectrograms: log frequency 30 Hz – 8 kHz, dashed line =
expected firing frequency `rpm / 60 × cylinders / 2`.

Sweeps (3 s): **wot** idle → redline at full throttle in 2nd, last 0.4 s on the rev limiter;
**lift** full throttle near 80 % redline then a lift (overrun, crackle, blow-off on turbo cars);
**shift** 2nd-gear pull, 0.25 s clutch shift (cut + rpm drop), 3rd-gear pull; **damaged** WOT at
35 % engine health (misfires).
