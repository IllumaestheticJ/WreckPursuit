# WreckPursuit

Physics-driven street racing: sim-cade handling, semi-soft-body damage, a living city with
traffic and police, asymmetric multiplayer. Rust core (native + WASM) with a Three.js testbed.

- Conventions: [`CLAUDE.md`](CLAUDE.md)
- Crate map, data flow, how to run: [`docs/INTEGRATION.md`](docs/INTEGRATION.md)
- Contract history: [`docs/CONTRACT_CHANGELOG.md`](docs/CONTRACT_CHANGELOG.md)
- What works / what is stubbed: [`docs/STATUS.md`](docs/STATUS.md)

Quick start: `just test`, `just web` (http://localhost:5173), `just sim apps/simcli/scenarios/smoke/straight_line.ron`.
